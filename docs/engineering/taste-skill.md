# Taste Skill

## What it does

Applies "taste" principles: expressive typography, intentional color, generous whitespace, subtle motion. Anti-template, anti-generic.

## When to reach for it

- Landing pages
- Marketing sites
- Portfolio
- Any public-facing page

## Common questions

**How is it different from impeccable?**
impeccable = production-ready polish. taste = personality, opinion, soul.

**Does it work with existing design system?**
Adapts. Doesn't break.

## It's working if

Page has distinct "voice". Doesn't look like a template.
