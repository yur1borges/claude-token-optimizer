# Verification Before Completion

## What it does

Blocks claim without evidence: test output, build log, screenshot, diff. Forces: "tests pass: [output]" not "tests pass".

## When to reach for it

- Always. Mandatory guardrail.

## Common questions

**For non-code tasks?**
Yes. Evidence = relevant output (file created, command ran, etc.)

**Can it be disabled?**
No. Hard rule in CLAUDE.md.

## It's working if

Zero claims without evidence in history.
