# Teste Leigo

## What it does

Simulates user who: doesn't read instructions, clicks wrong, impatient, doesn't know shortcuts. Finds UX bugs devs miss.

## When to reach for it

- Desktop apps (Tauri, Electron, WPF)
- Critical user flows
- Before release

## Common questions

**Does it replace automated tests?**
No. Complements. Catches UX, not logic bugs.

**How long?**
15-30 min per main flow.

## It's working if

Finds > 3 UX issues per flow tested.
