# Impeccable

## What it does

Applies design principles: hierarchy, spacing, color, motion, accessibility. Generates React/TSX + Tailwind production-ready.

## When to reach for it

- Landing pages
- Admin dashboards
- Design system components
- Any UI end users see

## Common questions

**Do I need a design system?**
No. Creates from scratch if none exists.

**Does it work with shadcn/ui?**
Yes. Uses it if detected.

## It's working if

Component passes checklist: responsive, accessible, dark mode, reduced motion, 0 console errors.
