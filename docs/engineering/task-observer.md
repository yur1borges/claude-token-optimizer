# Task Observer

## What it does

Records: steps, tools used, time, errors, decisions. Generates report at end with patterns and skill suggestions.

## When to reach for it

- Complex workflows
- Skill debugging
- Process optimization

## Common questions

**Does it save sensitive data?**
No. Only execution metadata.

**Where is the report?**
`.claude/task-observer/` in the project.

## It's working if

Report generated with > 3 actionable insights.
