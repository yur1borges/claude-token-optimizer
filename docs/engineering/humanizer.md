# Humanizer

## What it does

Replaces hedging ("I think", "it seems"), removes robotic structure, varies sentence length, injects personality.

## When to reach for it

- Docs, READMEs, posts
- Code comments
- Any text read by humans

## Common questions

**Does it change meaning?**
No. Only style.

**Does it work in pt-BR?**
Yes. Trained in Portuguese.

## It's working if

Text passes AI detector (GPTZero, etc.) as human.
