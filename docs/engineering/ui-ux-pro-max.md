# UI/UX Pro Max

## What it does

Applies 79 style patterns + 192 color palettes. Checks: contrast, focus order, touch targets, motion, dark mode, RTL. Generates report with fixes.

## When to reach for it

- Design system audit
- Accessibility (WCAG AA/AAA)
- Design tokens, themes
- Component library review

## Common questions

**Web only?**
Mainly web. Mobile: similar principles.

**Needs Figma?**
No. Analyzes rendered code.

## It's working if

0 WCAG AA violations. Design tokens consistent.
