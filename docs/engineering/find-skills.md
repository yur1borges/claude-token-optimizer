# Find Skills

## What it does

Searches configured marketplaces (claude-plugins-official, ponytail, caveman, ecc, mattpocock, etc.) and shows relevant skills with triggers and descriptions.

## When to reach for it

- Need a skill for a specific task
- Want to explore available marketplaces
- Don't know which skill to use

## Common questions

**Does it only search installed skills?**
No. Searches remote marketplaces too.

**Does it install automatically?**
Shows install command. You run it.

## It's working if

You find the right skill in < 30 seconds.
