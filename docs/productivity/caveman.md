# Caveman

## What it does

Removes: greetings, hedging, recap, "happy to help". Keeps: code, commands, paths, numbers, errors. 1 idea per sentence. Articles optional.

## When to reach for it

- Want dense output, zero fluff
- Tokens expensive / context limited
- Reading in terminal

## Common questions

**Does it break grammar?**
No. Voice, not broken grammar. Clarity > compression.

**Levels?**
`/caveman` (default), `/caveman ultra` (ultracave), `/caveman wenyan` (megacave).

## It's working if

Output 40-60% smaller. Zero ceremony. All technical info intact.
